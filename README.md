# 名古屋・鈴鹿の栞

2026年9月13日（日）〜15日（火）、大人2人と6歳・3歳で行く名古屋・三重の旅のしおり。
スマホのブラウザで開く前提で作ってある。電話番号はタップで発信、住所はタップで地図が開く。
持ち物のチェック状態は端末ごとに localStorage へ保存される。

## ファイル

| ファイル | 役割 |
| --- | --- |
| `栞.html` | 本文の原本。編集はここだけを触る |
| `index.html` | 公開用に書き出したもの。直接編集しない |
| `build.mjs` | `栞.html` から `index.html` を生成する |

## 更新のしかた

```
node build.mjs
git add -A && git commit -m "..." && git push
```

`index.html` はビルドの出力なので、手で直すと次のビルドで消える。

## 中身の扱い

- 飛行機・宿の情報はスカイパックツアーズの予約画面から書き写したもの
- 入場料と開館時間はトヨタ産業技術記念館・鈴鹿サーキットパークの公式サイトで確認（2026年9月時点）
- 列車の時刻は所要時間からの逆算。当日の発車時刻は乗換案内で確認すること
